# dsh-desk-stickers

给 **DeepSeek Harness** 桌面端贴几张顺手的「贴纸」。每张贴纸都能单独开关，互不影响；
所有设置都在 **设置 → 桌面** 里。

名字叫 stickers，是因为它不提供任何「AI 能力」——它只在你眼睛常看的窗口四周，
贴几个顺手的小物件。

| 贴纸 | 它是干什么的 |
|---|---|
| 📌 窗口置顶 | 标题栏右侧的置顶图标：一点，窗口浮在所有软件最前；再一点取消。按下有果冻弹跳，方框表示正在置顶 |
| 📑 侧栏折叠 | 左侧栏两处折叠条：收起整串菜单 / 收起「工作区」下的会话列表 |
| 🗒️ 便利贴 | 对话右上角的便签按钮：打开一张**真的浮在桌面最上层**的便签，能拖能拉，每个会话各自一张 |
| 🧾 已安装插件 | 「桌面」页里的插件清单：一键检查更新（全部一起查）、一键更新（严格一个一个装）、重启按钮 |
| 🔄 一键重启 | 上面那个重启按钮，另有 `/restart` 指令与 `restart_dsh` 工具 |

## 颜色默认是「吸色」的

置顶图标和两条折叠条**默认不设任何固定颜色**：它们各自去读自己所在位置的文字颜色，
所以换皮肤当场就跟着变，不需要你点任何按钮。

- 置顶图标 → 跟随侧栏菜单文字色
- 上方折叠条 → 跟随菜单文字色
- 下方折叠条（「工作区」那个箭头）→ 跟随「工作区」标题色

想自己指定也行：每处都有「跟随皮肤 / 颜色（色板 + 十六进制）」两行，填了就变成自定义，
点一下「跟随皮肤」就回到吸色。

## 安装

```bash
# 从 GitHub 装（DSH 会把它钉到当前提交上）
dsh plugin add github:purakkon/dsh-desk-stickers

# 以后有新版本
dsh plugin update dsh-desk-stickers
```

装完**重启一次 DSH**，新插件才会被挂载。

> 也可以发布到 npm 后用 `dsh plugin add dsh-desk-stickers`，二选一。

## 设置

**设置 → 桌面**，每张贴纸一张开关；「已安装插件」和「重启」在同一页标签里。

- 配置文件：`~/.dsh/data/desk-stickers/settings.json`
- 便利贴内容：`~/.dsh/data/sticky-note/`（关掉开关只是拿掉按钮，已经写下的便签不会丢）

## 各贴纸的细节

**置顶**：靠一个 PowerShell 小脚本调系统接口把窗口钉在最上层，按钮本身不重画窗口。
标题栏属于系统的拖动区，所以按钮额外做了 `-webkit-app-region: no-drag` 与 `pointerdown`
兜底，否则点不到。

**侧栏折叠**：两条折叠条都直接锚在原生侧栏上，不重画侧栏。折叠状态存在浏览器本地
（`localStorage`），刷新后保持。

**便利贴**：便签是真的独立桌面窗口（系统窗口 + Edge/Chrome 的 app 模式），不是页面里的浮层，
所以它能浮在别的软件上面。表格按迷你电子表格来做：
`＋行 / ＋列 / －行 / －列`、点行列表头整行整列选中、`Delete` 清空、拖边框改列宽行高、
右键菜单里改列宽行高、底部有横向滚动条；拉大窗口不会把单元格撑变形。

**已安装插件**：检查更新是**全部并行**（只读请求，互不干扰）；更新是**严格串行**——
每个安装都会重写同一份 profile 清单，同时装两个会互相覆盖（这一条是把插件装丢过之后
才改的）。更新完会核对「依赖 vs 挂载列表」，把被弄丢的挂载补回来。

## 平台

Windows 完整可用（置顶、便利贴的桌面窗口都依赖 Windows）。其它平台其余贴纸照常，
置顶与便利贴的桌面窗口会隐藏。

## 开发

```bash
node test/settings.test.mjs   # 15 条断言，零依赖（只在仓库里有，安装出去的包不含 test/）
```

结构：

- `index.js` — 宿主半边：设置读写、置顶、重启、插件清单四条路由
- `client.js` — 浏览器半边：五个贴纸的界面与取色逻辑
- `lib/*.mjs` — 各功能实现；`lib/*.ps1` — Windows 上的系统调用
- `cordis.patch.yml` — bundle 层，挂载 `desk-stickers` 这一个插件条目
